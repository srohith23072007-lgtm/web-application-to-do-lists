# 📝 To-Do List Web Application

A simple, responsive, and user-friendly To-Do List web application built using **HTML, CSS, and JavaScript**.

## 📌 Project Description

The To-Do List Web Application helps users create and manage their daily tasks. Users can add new tasks, mark tasks as completed, and delete tasks when they are no longer needed.

The project uses **Local Storage** to save tasks in the browser, so tasks remain available after refreshing or reopening the page.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 🔢 Display remaining task count
- ⌨️ Press Enter to add a task
- 💾 Save tasks using Local Storage
- 📱 Responsive design
- 🎨 Simple and clean user interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive functionality
- **Local Storage** – Saving tasks in the browser

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in Chrome, Edge, or another web browser.
4. Enter a task and click **Add**.

## 💻 How It Works

### Add Task
Enter a task in the input box and click **Add**.

### Complete Task
Click the checkbox next to a task to mark it as completed.

### Delete Task
Click **Delete** to remove a task.

### Save Tasks
Tasks are automatically stored in the browser using Local Storage.
